deployer packages

This site hosts the signed apt repository and the installer of deployer, a single-server deployment platform for Debian 13 (trixie), amd64: nginx with HTTP/3 in front, rootless Podman, ACME certificates, zero-downtime deploys and automatic updates.

Install

On a fresh Debian 13 server, as root:

curl -fsSL https://get.brakkit.com/install.sh | sudo sh

Beta channel: curl -fsSL https://get.brakkit.com/install.sh | sudo sh -s -- --channel beta. Read the script first if you like: install.sh. It sets up this repository and nginx.org's, installs the deployer package and runs deployer setup.
